# AI Team Demo

This is a small static web demo that visualizes a simple AI-supported team task board.

## Files

- `index.html` - page structure
- `styles.css` - layout and visual styling
- `app.js` - task rendering, filtering, and form handling

## Run locally

Open `index.html` directly in a browser, or serve the folder with a lightweight static server such as:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
