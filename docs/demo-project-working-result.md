# Demo Project Working Result

## Summary

A demo project was created at `prj/ai-team-demo` as a small static web application.

## What was built

- a landing page describing an AI-supported team workflow
- a task entry form with title, owner, and status
- a filterable task board with seeded example items
- responsive styling with no external dependencies

## Project files

- `prj/ai-team-demo/index.html`
- `prj/ai-team-demo/styles.css`
- `prj/ai-team-demo/app.js`
- `prj/ai-team-demo/README.md`

## How to use

1. Open `prj/ai-team-demo/index.html` in a browser, or serve the directory with a static file server.
2. Add a task with the form.
3. Filter tasks by status from the board header.

## Notes

- The demo is intentionally dependency-free for easy review and execution.
- The content is aligned with the repository theme of AI-supported team development.
